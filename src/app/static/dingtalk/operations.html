⚠️ 本页全部是写操作，会真实影响钉钉侧数据。未勾选「已确认执行」时后端会追加 --dry-run 只做预演，不会产生任何改动；勾选后才追加 --yes 真实执行。 写操作还需要后端开启 DINGTALK_ENABLE_WRITE=true。

快捷办理

日程、待办、消息、DING、在线表格、日报日志、群公告与机器人推送，一个表单对应一条接口。

📅 创建日程

POST /calendar

在钉钉日历中创建日程/会议，可按姓名邀请参会人。时间需为 ISO8601 格式。

✅ 给自己建待办

POST /todo

创建一条属于自己的钉钉待办，可设置截止时间。

🙋 指派待办给同事

POST /todo/assign

给某位同事创建并指派一条待办，执行人可填姓名或花名。

💬 发单聊消息

POST /message/send

给某位同事发钉钉单聊消息，内容支持 Markdown。

📢 发群消息

POST /group-message/send

给指定钉钉群发消息，群名不唯一时建议先用「信息查询」页的群搜索确认群名。

🔔 发送 DING 强提醒

POST /ding/send

打扰性较强，请谨慎使用。接收人需要 openDingTalkId（可用「信息查询」页的通讯录搜索解析）。

📊 创建在线表格

POST /sheet

新建一篇钉钉在线电子表格；文件夹 ID / 知识库 ID 可选，不填则使用默认位置。

📝 提交日报日志

POST /log

按日志模板提交；contents 是需要提交的 JSON 数组字符串，每项包含 key / sort / content / contentType / type。模板 ID 可在钉钉日志模板页获取。

📌 发布群公告

POST /notice

在指定群发布公告，正文为 Markdown。conversation_id 是群的 openConversationId，可在「信息查询」页用群搜索获取。

🤖 机器人推送

POST /robot-message/send

通过群自定义机器人 Webhook 推送到机器人所在群；Webhook token 由后端 DINGTALK_ROBOT_WEBHOOK_TOKEN 配置，内容需包含机器人安全设置的关键词。
