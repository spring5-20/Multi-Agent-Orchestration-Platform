信息查询

只读查询：登录状态、通讯录、今日日程、我的待办、收到的日志、今日考勤与群聊搜索。结果均为 dws CLI 原始输出，可一键复制；页面底部还可以直接用自然语言指挥钉协助手。

🔐 账号登录

POST /auth/login

首次使用或登录过期时，点击按钮触发本机浏览器扫码授权；授权完成后顶部的「钉钉账号」徽标会自动变为已登录。

登录状态查看 GET /auth/status

🔍 通讯录搜索

GET /contact/search

按姓名或花名找人，返回 userId、部门、职位；发消息、指派待办前可先在这里取 userId。

👥 群聊搜索

GET /group/search

按群名关键词搜索，返回群名称与 openConversationId；发布群公告时需要先在「快捷办理」页填入该 ID。

📅 今日日程

GET /calendar/list

查询今天的钉钉日程安排，无需任何参数。

✅ 我的待办

GET /todo/list

查询自己的钉钉待办，可按优先级过滤。

📝 收到的日志

GET /log/list

查询我收到的钉钉日志（日报 / 周报）。

🕒 今日考勤

GET /attendance

查询我今天的钉钉考勤打卡流水。

💬 和钉协助手对话

在线

用一句话描述需求，智能体会自动挑选合适的钉钉工具执行；流式接口为 POST /chat（SSE）。 对话里涉及写操作时只会预演（不会真的发出去）：真实执行请到「快捷办理」提交，或在「多智能体」控制台里点「确认执行」。
